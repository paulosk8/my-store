Visualización del Flujo de Autenticación JWT con Passport.js

Una vista previa interactiva de los dos procesos clave.

Parte 1: Flujo de Login (Autenticación)

Este proceso describe cómo un usuario envía sus credenciales y recibe un token JWT a cambio.

                    graph TD
                        subgraph "Flujo de Login"
                            direction TB

                            Client_Login((Cliente)) -- "1. POST /login con (email, password)" --> Route_Login[Endpoint: /login];
                            Route_Login -- "2. Invoca a passport.authenticate('local')" --> Passport_Local_Auth{Estrategia 'local' de Passport};

                            Passport_Local_Auth -- "3. Busca usuario en DB por email" --> DB_Users1[Base de Datos];
                            DB_Users1 -- "Retorna usuario" --> Passport_Local_Auth;

                            Passport_Local_Auth -- "4. Compara contraseña enviada con la de la DB" --> ComparePass{¿Contraseña válida?};
                            ComparePass -- "NO ❌" --> Error_Response[Responde 401 Unauthorized];
                            Error_Response --> Client_Login;

                            ComparePass -- "SÍ ✅" --> Generate_Token[5. Genera Token JWT];
                            Generate_Token -- "Payload: (sub, role)" --> JWT_Code["Lógica: jwt.sign(payload, secret)"];

                            JWT_Code -- "6. Envía respuesta al cliente" --> Send_Token["JSON: (token: ...)"];
                            Send_Token --> Client_Login;
                        end

Parte 2: Flujo de Acceso a Ruta Protegida (Autorización)

Este proceso muestra cómo se valida un token JWT para permitir el acceso a un recurso protegido.

                    graph TD
                        subgraph "Flujo de Ruta Protegida"
                            direction TB

                            Client_Protected((Cliente)) -- "1. GET /my-orders 
Header: Authorization: Bearer [token]" --> Route_Protected[Endpoint: /my-orders];
                            Route_Protected -- "2. Middleware passport.authenticate('jwt') intercepta" --> Passport_JWT_Auth{Estrategia 'jwt' de Passport};

                            Passport_JWT_Auth -- "3. Extrae token del header" --> Extract_Logic["Lógica: ExtractJwt.fromAuthHeaderAsBearerToken()"];
                            Extract_Logic -- "4. Verifica firma y expiración del token" --> Verify_Token{¿Token válido?};

                            Verify_Token -- "NO ❌" --> Error_Response_JWT[Responde 401 Unauthorized];
                            Error_Response_JWT --> Client_Protected;

                            Verify_Token -- "SÍ ✅" --> Attach_User[5. Payload del token se pasa a la función 'done'];
                            Attach_User --> Attach_User_Code["Lógica: done(null, payload) 
 Passport adjunta el payload a req.user"];

                            Attach_User_Code -- "6. El control pasa al controlador" --> Controller_Access[7. Controlador accede a req.user];
                            Controller_Access -- "Usa 'req.user.sub' para la consulta" --> DB_Orders[Base de Datos];

                            DB_Orders -- "Retorna datos del usuario" --> Controller_Access;
                            Controller_Access -- "8. Responde con los datos" --> Client_Protected;
                        end
